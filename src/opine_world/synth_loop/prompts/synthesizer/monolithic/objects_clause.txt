STATE CHANGES ARE COUPLED, AND THE COUPLING IS GUARDED BY PRECONDITIONS. The transition_function's job is to encode the FULL STATE UPDATE that fires in response to an action: 'this part of the state changes only when condition C on world state holds.' The updates are rarely one-record-in-isolation. The co-variation of records across transitions in the replay buffer is your primary evidence. when record X changes, what else changes with it? Under what state did that co-variation occur, and when did it NOT occur even though X was acted on?
