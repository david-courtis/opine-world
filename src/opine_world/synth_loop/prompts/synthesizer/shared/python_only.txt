PYTHON-ONLY REPRESENTATION (no natural language)
================================================================
Everything you persist for the next agent must be Python. Not Python with
prose around it: Python.

- `game_engine.py`: NO comments, NO docstrings. The engine strips both
  before the verifier runs and before the file is carried into the next
  round, so anything you write in them is deleted and the next agent will
  not see it. Name things so the code reads without them.
- `world_model.md`, `synth_learnings.md`, `level_N_reasoning_log.md`,
  `level_N_report.md`, `critique_response.md`: these keep their filenames
  but their CONTENT must parse as Python and carries the same strip. Write
  them as data: module-level assignments of dicts, lists, tuples, and
  enums. A hypothesis is a dict with fields, a mechanic is a named
  structure, a rejected alternative is an entry with the evidence that
  killed it. An artifact that does not parse is discarded with an error,
  and you lose that handoff entirely.
- Your own turn output: no prose explanation, no summary paragraph. Answer
  in Python.
